YAK-52 GROUND SCHOOL - installable version

Use this if you want it as an app icon on your phone's home screen that opens with no signal.

1. Unzip this folder.
2. Put the folder on any static web host once. The quickest: drag the unzipped folder onto
   https://app.netlify.com/drop (free, no account needed for a temporary site), or use GitHub Pages.
3. Open the site address on your phone:
     iPhone (Safari): Share > Add to Home Screen
     Android (Chrome): menu > Install app / Add to Home screen
   On a laptop in Chrome or Edge: the install icon in the address bar.
4. Open it once while online. After that it works fully offline.

If you'd rather not host it: yak52-ground-school.html (the single file) opens straight from
your laptop or phone's files in a browser and also works offline.

Progress (flashcards, quiz scores, checklist ticks) is saved separately on each device and browser.
